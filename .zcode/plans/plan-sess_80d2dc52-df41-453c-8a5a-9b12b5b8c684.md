# 按 shadcn 文档站设计语言重构项目 UI

## 目标与结论

把 **商家后台**（/admin 列表、新建、详情、登录、导航）对齐 ui.shadcn.com 的设计语言：中立灰单色、细边框卡片、克制的留白、Geist 字体、组件化的卡片/表格/徽章。**客户订购页/群填单页保持你已调好的移动电商版式**，只统一基调（按钮档位、圆角、mono 字体）。

可行性已核实：项目 token 层与文档站完全同源（globals.css 就是 shadcn neutral 灰 oklch 值 + `--radius: 0.625rem`，全站几乎零硬编码颜色，基础组件已是 Base UI 版 shadcn 形态）。这次的工作量在**统一组件形态**，不在换色，属于低成本高回报。

## 改动清单

**1. 全局基座（2 个文件）**
- `src/app/layout.tsx`：补 Geist Mono → `--font-mono`（文档站特色的数字/口令等宽排版）
- `src/app/globals.css`：接入 `--font-mono`；顺手校准 `.dark` 变量值为 shadcn neutral 标准（为将来启用暗色铺路，本次不放开强制浅色）

**2. 补齐缺失的 shadcn 基础组件**
- `npx shadcn add card badge table alert-dialog`（自动按本项目 Base UI base 生成）
- `src/lib/sheetStatus.ts`：改为返回语义状态而非 class 字符串，样式归 Badge（消除 lib 层泄漏样式）

**3. 后台版式重构（核心）**
- **AdminNav → 文档站同款站点头部**：`sticky h-14 border-b bg-background/95 backdrop-blur`，品牌 + 当前页 active 态导航 + 退出 ghost 按钮（现为无边框裸文本条）
- **页面头部模式**：各页统一「标题 `font-semibold tracking-tight` + muted 描述 + 右侧操作区」的文档站 page-header 结构
- **卡片统一**：后台所有手写卡片容器（现存三套配方并存）→ `Card` 组件（rounded-xl + border，无阴影）；新建页三张节卡同改
- **表格统一**：4+ 处手写 `<table>` → `Table` 组件；表头 muted 小字、价格/数量/口令等数字列 `font-mono tabular-nums`
- **徽章统一**：手搓胶囊 → `Badge`（进行中/已截止/已关闭三态）
- **弹窗对齐**：Dialog 遮罩 `bg-black/10` → shadcn 默认 `/50`；Modal 容器 rounded-2xl → rounded-xl；启用一直没用上的 `DialogFooter`；GroupLinkCard/SheetActions 里 2 处原生 `confirm()` → `AlertDialog`
- **按钮尺寸归队**：Button 新增 `size="xl"`（h-12 rounded-xl）承接大 CTA，消除脱离 cva 体系的临时 h-12 覆写

**4. 客户页轻改（不动版式）**
- JoinForm/OrderForm 的按钮覆写换 `size="xl"`；口令等输入统一 mono 字体；电商卡片版式、红价、大图、底栏全部保留

**5. 验收**
- `npm run lint` + `npm run format` 通过
- 浏览器逐页截图核对（后台 4 页 + 移动端宽度下的订购/群填单页），确认无布局破坏
- 全程不改业务逻辑与接口

## 明确不做

- 客户页版式重构（保留电商风）
- 暗色模式放开（token 校准就绪但 forcedTheme 保持原样；之后想启用只需改 layout.tsx 一行 + 导航加切换按钮）
- 不新增业务功能

涉及约 18 个文件（含 4 个新增 ui 组件），dev server 热更新可直接在浏览器验收。
